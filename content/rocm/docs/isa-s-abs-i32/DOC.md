# S_ABS_I32

Compute the absolute value of a scalar input, store the result into a scalar register and set SCC iff the result is nonzero.

## Encoding

Encoding: `ENC_SOP1`
Opcode: `48`


## Operands

| Field | Type | Size | Direction | Implicit |
|-------|------|------|-----------|----------|
| SDST | SDST | 32bit | out | no |
| SSRC0 | SSRC | 32bit | in | no |
|  | SSRC_SPECIAL_SCC | 1bit | out | yes |
| LITERAL | SSRC | 32bit | in | no |
