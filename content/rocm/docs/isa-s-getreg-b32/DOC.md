# S_GETREG_B32

Read some or all of a hardware register into the LSBs of destination.

## Encoding

Encoding: `ENC_SOPK`
Opcode: `17`


## Operands

| Field | Type | Size | Direction | Implicit |
|-------|------|------|-----------|----------|
| SDST | SDST | 32bit | out | no |
| SIMM16 | HWREG | 16bit | in | no |
