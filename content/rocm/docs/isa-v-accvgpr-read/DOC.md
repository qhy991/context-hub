# V_ACCVGPR_READ

Move 32 bits of data from an accumulator vector register into an architectural vector register.

## Encoding

Encoding: `ENC_VOP3P`
Opcode: `88`


## Operands

| Field | Type | Size | Direction | Implicit |
|-------|------|------|-----------|----------|
| VDST | VGPR | 32bit | out | no |
| SRC0 | SRC_ACCVGPR | 32bit | in | no |
