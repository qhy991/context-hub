# DS_READ_B96

Load 96 bits of data from a data share into a vector register.

## Encoding

Encoding: `ENC_DS`
Opcode: `254`


## Operands

| Field | Type | Size | Direction | Implicit |
|-------|------|------|-----------|----------|
| VDST | VGPR_OR_ACCVGPR | 96bit | out | no |
| ADDR | VGPR | 32bit | in | no |
|  | DSMEM | 96bit | in | yes |
