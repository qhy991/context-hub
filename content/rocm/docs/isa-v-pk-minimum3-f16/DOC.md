# V_PK_MINIMUM3_F16

Select the component-wise IEEE minimum() of three half-precision float inputs and store the result into a vector register.

## Encoding

Encoding: `ENC_VOP3P`
Opcode: `27`


## Operands

| Field | Type | Size | Direction | Implicit |
|-------|------|------|-----------|----------|
| VDST | VGPR | 32bit | out | no |
| SRC0 | SRC_NOLIT | 32bit | in | no |
| SRC1 | SRC_SIMPLE | 32bit | in | no |
| SRC2 | SRC_SIMPLE | 32bit | in | no |
