# DS_WRITE_B8

Store 8 bits of data from a vector register into a data share.

## Encoding

Encoding: `ENC_DS`
Opcode: `30`


## Operands

| Field | Type | Size | Direction | Implicit |
|-------|------|------|-----------|----------|
| ADDR | VGPR | 32bit | in | no |
| DATA0 | VGPR_OR_ACCVGPR | 8bit | in | no |
|  | DSMEM | 8bit | out | yes |
