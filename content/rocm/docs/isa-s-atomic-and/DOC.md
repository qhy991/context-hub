# S_ATOMIC_AND

Calculate bitwise AND given two unsigned 32-bit integer values stored in the data register and a location in the scalar memory.

## Encoding

Encoding: `ENC_SMEM`
Opcode: `136`


## Operands

| Field | Type | Size | Direction | Implicit |
|-------|------|------|-----------|----------|
| SDATA | SREG | 32bit | out | no |
| SBASE | SREG | 64bit | in | no |
| SOFFSET | SMEM_OFFSET | 32bit | in | no |
